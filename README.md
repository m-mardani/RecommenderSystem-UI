# RecommenderSystem-UI

رابط کاربری پیشرفته Next.js برای سیستم توصیه‌گر مبتنی بر FastAPI

## معرفی

این پروژه یک رابط کاربری کامل و حرفه‌ای برای سیستم توصیه‌گر است که با استفاده از فناوری‌های مدرن وب ساخته شده است.

## ویژگی‌های کلیدی

- ✅ **Next.js 16** با TypeScript
- ✅ **TailwindCSS** برای طراحی واکنش‌گرا
- ✅ **JWT Authentication** با تازه‌سازی خودکار توکن
- ✅ **Axios** برای مدیریت درخواست‌های HTTP
- ✅ **کنترل دسترسی مبتنی بر نقش** (ADMIN/USER)
- ✅ **پشتیبانی کامل از فارسی** (RTL + فونت Vazirmatn)
- ✅ **مدیریت حالت‌های بارگذاری و خطا**
- ✅ **صفحات کامل**: ورود، داشبورد، داده‌ها، آموزش، پایش، مدل‌ها، توصیه‌ها
- ✅ **سازگاری دوحالته با backend**: پشتیبانی از API زنده و contract جدید split شده‌ی `USER/ADMIN`

## صفحات پیاده‌سازی شده

### 🔐 احراز هویت
- **صفحه ورود** - ورود کاربران با نام کاربری و رمز عبور
- **صفحه ثبت‌نام** - به صفحه اطلاع‌رسانی تغییر کرده چون ثبت‌نام عمومی غیرفعال است

### 📊 داشبورد
- نمایش آمار کلی سیستم (تعداد داده‌ها، مدل‌ها، کارهای فعال)
- دسترسی سریع به عملکردهای اصلی
- کارت‌های اطلاعاتی با آیکون‌های جذاب

### 💾 مدیریت مجموعه داده‌ها
- لیست نمایش مجموعه داده‌ها
- بارگذاری فایل CSV/JSON
- حذف مجموعه داده‌ها
- نمایش اطلاعات تعداد سطر و ستون

### 🧠 آموزش مدل
- انتخاب مجموعه داده
- انتخاب نوع مدل (فیلتر مشارکتی، محتوا، ترکیبی، و...)
- شروع فرآیند آموزش

### 📈 پایش کارهای آموزشی
- نمایش وضعیت کارها (در انتظار، در حال اجرا، تکمیل شده، ناموفق)
- نمایش پیشرفت آموزش
- بروزرسانی خودکار هر 5 ثانیه
- امکان لغو کارها

### 🎯 مدل‌های آموزش داده شده
- لیست مدل‌های موجود
- نمایش معیارهای عملکرد
- استفاده از مدل برای توصیه
- حذف مدل‌ها

### ⭐ دریافت توصیه‌ها
- ورودی شناسه کاربر
- انتخاب مدل
- تعداد توصیه‌های مورد نیاز
- نمایش نتایج در جدول

## شروع سریع

### پیش‌نیازها

- Node.js 18+
- npm یا yarn
- سرور FastAPI در حال اجرا

### نصب

```bash
cd frontend
npm install
```

### تنظیمات

فایل `.env.local` را ایجاد کنید:

```bash
cp .env.example .env.local
```

و آدرس API را تنظیم کنید:

```env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000/api/v1
```

### اجرا

```bash
npm run dev
```

برنامه در آدرس [http://localhost:3000](http://localhost:3000) در دسترس خواهد بود.

## ویژگی‌های امنیتی

### 🔒 JWT Authentication
- Access Token برای احراز هویت درخواست‌ها
- Refresh Token برای تازه‌سازی خودکار
- مدیریت خودکار توکن‌های منقضی شده

### 🛡️ محافظت از مسیرها
- تمام صفحات به جز ورود محافظت شده‌اند
- صفحه `register` فقط وضعیت غیرفعال بودن ثبت‌نام را توضیح می‌دهد
- هدایت خودکار کاربران غیرمجاز به صفحه ورود

### 👥 کنترل دسترسی مبتنی بر نقش
- تفکیک کاربران ADMIN و USER
- محدودیت دسترسی بر اساس نقش کاربر

## API Endpoints مورد نیاز

بک‌اند FastAPI باید endpoint های زیر را فراهم کند:

**احراز هویت:**
- `POST /api/v1/auth/login`
- `POST /api/v1/auth/logout`
- `POST /api/v1/auth/refresh`
- `GET /api/v1/auth/me`

**مدل‌های user-facing:**
- `GET /api/v1/models/available`
- fallback: `GET /api/v1/engine/models/me`

**مجموعه داده‌ها و آموزش:**
- `GET /api/v1/engine/datasets/db`
- `POST /api/v1/engine/datasets/upload`
- `POST /api/v1/engine/train`
- `POST /api/v1/engine/train/auto`

**مدل‌ها و توصیه‌ها:**
- `GET /api/v1/admin/models`
- `DELETE /api/v1/engine/models/{job_id}`
- `GET /api/v1/engine/jobs/{job_id}/recommend`
